# Adult Income Prediction — Applied ML Project

- **Course:** Applied ML: Foundations, Engineering & Evaluation (MSA-DATI07-05), Albert School
- **Dataset:** Option 1, **Adult / Census Income** ([OpenML `adult`, version 2](https://www.openml.org/d/1590)), 48,842 people from the 1994 US census
- **Task:** binary classification, predict whether a person earns **more than $50K/year** (`>50K`, 23.9% of rows)
- **Sensitive attribute (fairness audit):** `sex`
- **Final report:** [`report/report.pdf`](report/report.pdf)

**Main result:** LightGBM, test PR-AUC **0.837**, F1 **0.728** at a tuned threshold of 0.379, well calibrated (ECE 0.007);
group thresholds reduce the recall gap between women and men from 7.5 to 0.3 points.

## Setup and run

Requires Python 3.10 or later (tested with 3.12 and 3.14).

```bash
git clone https://github.com/acasagranda24/Applied-ML-project.git
cd Applied-ML-project
python -m venv .venv
source .venv/bin/activate          # Windows (PowerShell): .venv\Scripts\Activate.ps1
pip install -r requirements.txt

# from the project root, in this order
python -m src.eda         # ~10 s
python -m src.train       # ~5-7 min
python -m src.evaluate    # ~20 s (needs the models saved by src.train)
```

The data is downloaded automatically from OpenML the first time. Settings (seed, split size,
number of folds and of Optuna trials) are at the top of `src/prepare.py`. All results are reproducible
with `random_state=42`.

| Script | What it does | Outputs |
|---|---|---|
| `eda.py` | Exploratory analysis; prints each finding and the decision it led to | `reports/figures/eda_*.png` |
| `train.py` | Imbalance remedies, 4-model comparison, Optuna tuning, final model and threshold (development set only) | `reports/imbalance_remedies.csv`, `model_comparison.csv`, `tuned_models.csv`, `final_model.json`, `run_log.csv`, `figures/optuna_*.png`, `figures/model_comparison_pr_curves.png` |
| `evaluate.py` | The only script that uses the test set: final metrics, calibration, SHAP, fairness | `reports/test_metrics.csv`, `fairness_before_after.csv`, `figures/confusion_matrix.png`, `calibration_curve.png`, `shap_*.png`, `fairness_recall_by_sex.png` |

## Methodology

### Problem framing
- **Unit of decision:** one adult from the census. **Target:** income > $50K (binary).
- **Leakage audit:** all features are demographic / job attributes known before the income; none is derived from the target.
- **No-skill baseline:** a dummy classifier (PR-AUC 0.239 = the positive rate).

### Validation protocol
- Stratified **80% development / 20% test** split (`random_state=42`).
- Validation = **5-fold stratified cross-validation inside the development set**. The whole Pipeline is
  re-fitted in each fold, so preprocessing never sees validation rows.
- Every decision (remedy, model, hyperparameters, thresholds) is taken on the development set.
  The **test set is used once**, in `evaluate.py`.

### Cleaning and feature engineering
| Step | Justification (from `eda.py`) |
|---|---|
| Drop `fnlwgt` | census sampling weight, not a property of the individual |
| Drop `education` | exact duplicate of the ordinal `education-num` |
| Missing categories → `"Missing"` category | missingness is informative (P(>50K) = 9.5% when missing vs 24.8%) |
| `capital_net` = signed log(gain − loss) | >90% zeros and a very long tail |
| `has_capital` flag | owning investments is a wealth signal in itself |
| `overtime` flag (hours > 40) | non-linear effect of working hours |
| `native_us` flag | 91% US; 40 rare countries would give sparse one-hot columns |
| Median imputation, one-hot encoding, scaling for the linear model | all fitted inside the single Pipeline |

### Metrics
**PR-AUC (average precision)** is the selection metric: accuracy is misleading with 76% negatives.
We also report ROC-AUC, precision, recall, F1, accuracy and the Brier score.

### Class imbalance
Four remedies compared in 5-fold CV on LightGBM (resampling applied to training folds only, with an `imblearn` Pipeline):

| Remedy | CV PR-AUC | CV ROC-AUC | Precision @0.5 | Recall @0.5 | F1 @0.5 | Brier | F1 at best threshold |
|---|---|---|---|---|---|---|---|
| None | 0.829 | 0.929 | 0.777 | 0.657 | 0.712 | **0.088** | 0.727 |
| Class weights (`scale_pos_weight` = 3.2) | 0.829 | 0.929 | 0.607 | 0.867 | 0.714 | 0.109 | 0.728 |
| Random undersampling | 0.822 | 0.927 | 0.601 | 0.871 | 0.711 | 0.113 | 0.723 |
| Random oversampling | 0.828 | 0.929 | 0.609 | 0.860 | 0.713 | 0.108 | 0.727 |

No remedy improves the ranking. Weights and resampling only move the operating point towards recall and
degrade the probabilities (higher Brier). **Chosen remedy: no reweighting, PR-AUC as selection metric, and
a decision threshold tuned on out-of-fold predictions.** SMOTE was not used: interpolating between rows
has no meaning for one-hot encoded categories.

### Model progression and tuning
Same Pipeline, same folds, same metrics. Optuna (TPE), 15 trials per model; one trial = 5-fold CV of the
complete Pipeline. All trials are in `reports/run_log.csv`.

| Model | What the step adds | CV PR-AUC, default | CV PR-AUC, tuned (mean ± std) | CV ROC-AUC, tuned |
|---|---|---|---|---|
| Dummy | no-skill floor | 0.239 | — | 0.500 |
| Logistic regression | linear baseline | 0.735 | 0.735 ± 0.011 | 0.899 |
| Decision tree | thresholds and interactions | 0.758 | 0.789 ± 0.012 | 0.908 |
| Random forest | averaging many trees (less variance) | 0.801 | 0.811 ± 0.008 | 0.920 |
| **LightGBM** | sequential error correction | 0.829 | **0.830 ± 0.007** | **0.929** |

Each step buys PR-AUC, and the gaps between models are larger than the fold-to-fold standard deviation.
Tuning helps the single tree most (+0.03) and barely changes LightGBM.
**Final model: LightGBM.** Threshold tuned on out-of-fold predictions (max F1): **0.379**.

### Final evaluation on the test set (used once)

| | PR-AUC | ROC-AUC | Precision | Recall | F1 | Accuracy | Brier |
|---|---|---|---|---|---|---|---|
| Threshold 0.5 | 0.837 | 0.931 | 0.791 | 0.660 | 0.719 | 0.877 | 0.086 |
| Tuned threshold 0.379 | 0.837 | 0.931 | 0.711 | 0.745 | 0.728 | 0.867 | 0.086 |

Test PR-AUC (0.837) is consistent with the cross-validation estimate (0.830 ± 0.007).

### Calibration
Brier score **0.086**, ECE **0.007**. The reliability curve follows the diagonal; the largest gap is around
p ≈ 0.45 (observed 0.41, a slight over-estimation). The probabilities can be used as they are.

### Explainability
Top features by mean |SHAP|: `capital_net`, `age`, being married (`Married-civ-spouse`), `education-num`,
`hours-per-week`. They make business sense (wealth, seniority, household status, education, working time).
`sex_Female` ranks 8th with a negative effect, which motivates the fairness audit.
Local waterfall plots for a true positive, true negative, false positive and false negative are in `reports/figures/`.

### Fairness
Fairness definition targeted: **equal opportunity** (equal recall for men and women).
Mitigation: **one decision threshold per group** (post-processing), chosen on development out-of-fold
predictions (Female 0.264, Male 0.395), then applied once to the test set.

| Test set | Before | After |
|---|---|---|
| Recall, women / men | 0.681 / 0.757 | 0.751 / 0.748 |
| **Equal opportunity gap** | **0.075** | **0.003** |
| Demographic parity gap | 0.216 | 0.182 |
| F1 (overall) | 0.728 | 0.725 |

The recall gap is closed for a negligible overall cost. The price is paid in precision for women
(0.71 → 0.63), and the method needs the sensitive attribute at decision time. The demographic parity gap
remains because base rates differ in the data (30% of men vs 11% of women earn >50K).
