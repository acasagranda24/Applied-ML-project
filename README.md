# Adult Income Prediction — Applied ML Project

**Course:** Applied ML: Foundations, Engineering & Evaluation (MSA-DATI07-05), Albert School
**Dataset:** Option 1, **Adult / Census Income** (OpenML `adult`, version 2)
**Task:** binary classification, predict whether a person earns **more than $50K/year** (`>50K`, ~24% of rows).
**Sensitive attribute (fairness audit):** `sex`.

## Repository structure

```
adult-income-ml/
├── README.md
├── requirements.txt
├── src/
│   ├── prepare.py     # toolbox: settings, data split, features + Pipeline, models, metrics, run log
│   ├── eda.py         # 1. exploratory data analysis
│   ├── train.py       # 2. imbalance remedies, 4-model comparison, Optuna tuning, final model
│   └── evaluate.py    # 3. test metrics, calibration, SHAP, fairness
├── reports/
│   ├── figures/       # plots used in the report
│   ├── *.csv          # result tables
│   └── run_log.csv    # one line per training / tuning trial
├── models/            # saved models (not committed, regenerated by train.py)
└── data/              # downloaded data (not committed)
```

## Setup and run

```bash
git clone <repo-url>
cd adult-income-ml
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# from the project root, in this order
python -m src.eda         # ~10 s    prints key numbers, saves EDA figures
python -m src.train       # ~5 min   everything decided by cross-validation, saves the final model
python -m src.evaluate    # ~20 s    the only script that uses the test set
```

The data is downloaded automatically the first time. Settings (seed, split, number of Optuna trials)
are at the top of `src/prepare.py`.
